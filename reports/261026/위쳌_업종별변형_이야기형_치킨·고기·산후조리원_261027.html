위쳌 사업장 상세 — 이야기형(I·J안) 업종별 변형: 치킨집 · 고기집 · 산후조리원 (10/27)

"수많은 멤버스 사업장에 적용하면 다 똑같아지지 않을까"에 대한 답입니다. 틀(카드 문법 · 방문기 → 팩트 칩 → 리포트 흐름 · 전문가 서명)은 고정하고, 첫 장면 · 장면 순서와 개수 · 사장님 답변 · 사진 · 결론 한 줄만 업장마다 바꿨습니다. 같은 틀로 치킨집·고기집·산후조리원을 나란히 두면 서로 다른 글로 읽히는지 확인해 주세요. 사진은 아래 샷 리스트의 이름을 적은 자리로 두었습니다. 상호·수치·인터뷰는 시안용 예시입니다.

I안 · 인플루언서 디테일 설명형 — 같은 틀, 업장 세 곳첫 장면이 다르면 글 전체가 다르게 읽힙니다: 기름 → 숙성고 → 신생아실 공기
J안 · 사장님 인터뷰형 — 같은 틀, 업장 세 곳질문 풀에서 사장님이 고른 질문만 쓰니 17년 노포 · 정육 출신 3년차 · 간호사 출신 원장이 다른 이야기를 합니다

각주

  1. 식품위생법 시행규칙 [별표 17] 식품접객영업자 등의 준수사항: 튀김용 유지 산가 3.0 이하. 최신 개정 조문은 국가법령정보센터 원문 대조 필요.
  2. 확인 필요산화된 기름의 건강 영향은 공식 안내문 출처 확정 전이라 수치 없이 서술.
  3. 식품의약품안전처 캠필로박터 식중독 예방 안내: 주요 경로는 덜 익힌 닭고기와 생닭 세척 중 교차 오염.
  4. 확인 필요후드·덕트 기름때와 화재의 관계는 소방청 통계 출처 확정 전이라 수치 없이 서술.
  5. 확인 필요식육 냉장 보관 온도 기준(-2~10℃)은 축산물 위생관리법령 기준으로 적었으며 조문 대조 필요. 숙성고 1℃는 예시.
  6. 확인 필요ATP 200 RLU는 법정 기준이 아니라 관리 기준(세스코 내부 기준 또는 업계 통용치)으로 표기. 실제 세스코 기준값과 측정 장비 명칭에 맞춰야 함.
  7. 확인 필요산후조리원 총부유세균 유지기준 800 CFU/㎥는 실내공기질 관리법 시행규칙 [별표 2](의료기관·산후조리원·어린이집·노인요양시설)를 근거로 적었으며 조문 대조 필요.
  8. 확인 필요세 업장의 상호·수치·인터뷰·점검 횟수는 모두 시안용 창작 예시. 호텔·키즈카페 궁금증 세트는 1차 초안이며 업종 담당과 확인 필요.
