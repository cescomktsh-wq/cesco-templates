1. 회의 요청 사항 (10/16 · 10/21)

  • 로켓 3종은 말만 바꾼 변형이 아니라 유형별로 강조·레이아웃을 다르게 — 산업체는 위험 요소를 자세히 쓰고 "문의하세요"로, 소규모 사장님은 글은 적게 특장점·가격만 크게, 가정집은 집에서 생기는 문제와 특장점을 상세히.
  • 제품 리플릿은 USP가 세 번 반복되고 하단이 비는 문제를 없앨 것. "3스텝 관리"는 안 맞는 제품이 많으니 기본형에 고정하지 말고 기본형 + 기타형 두 트랙으로.
  • 프로모션 리플릿은 프로모션 정보가 없으면 작업 전에 되묻고, 상단에 제품 핵심이 담긴 타이틀 카피와 제품 요약을 넣을 것.
  • 공통: 공란 없이, 디자이너가 글자 크기·배열만 손보면 되는 수준으로.

2. 코퍼스 분석 결과 (10/22, 세스코 제품 리플릿 40건)

  • 구조를 판정할 수 있는 19건 중 13건이 가이드라인 여섯 자리를 그대로 쓰는 기본형이었습니다. 나머지는 가격표가 중심인 것 4건, 관리 단계(STEP)가 중심인 것 1건(에어컨 클리닝), Q&A형 1건.
  • STEP·SOLUTION 같은 순서 라벨은 서비스가 붙은 상품에만 있었고, 순수 제품은 1·2·3 장점 넘버링이었습니다. 그래서 관리 단계를 기본형에 넣으면 13건에 억지로 끼우는 셈이 됩니다.

3. 그래서 이렇게 정했습니다

  • 기본형 = 가이드라인 여섯 자리 그대로: 문제 제기 → 문제의 근거 → 제품 소개 → 특장점·각주 → 가격·문의. 보통 제품은 전부 이걸로.
  • 기타형은 코퍼스에서 많이 나온 순서로 번호를 붙였습니다: 기타형 1 가격표형(4건) · 기타형 2 관리 단계형(1건) · 기타형 3 Q&A형(1건). 에어컨 클리닝처럼 "어떤 순서로 해 주느냐"가 곧 상품인 것만 기타형 2.
  • 시안: 기본형 = 프레쉬제닉 Max, 기타형 2 = 에어컨 클리닝. 10/26 피드백(문제 제기 → 원인 → 해결책 → 세스코 상품 흐름 누락)을 받아 제품 2종·로켓 3종을 그 흐름으로 다시 짰고, 로켓은 유형별 강조를 갈랐습니다.
  • 남은 일: 지면 분량을 2P에 맞게 줄이기, 검수 하네스. 센스미 프로모션 테스트본은 10/27 1안·2안 실물 시안으로 공유(프로모션 행 산출물).
