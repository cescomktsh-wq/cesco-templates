# 카드뉴스 매트리스 케어 편 · 스토리 유형 검토 (2026-10-27)

## 1. 본편 흐름과 배수구 편 4유형 대조
- 매트리스 본편 6장: 표지(단정형 "이불은 빨았는데 매트리스 속 진드기는 그대로입니다" + 서브에서 원인 지목) → 근거 1(40℃ 사멸률 9.6%) → 근거 2(면 시트 차단 66%) → 셀프 팁 3항(3번이 솔루션 연결) → 솔루션 1장 → 마무리.
- 원인 추적형(배수구 7장): 표지(증상 "저녁이면 돌아오는 냄새" + 서브에서 원인 지목) → 원인 → 확산 → 셀프 팁 3항 → 솔루션 2장 → 마무리. 장표 순서가 매트리스 본편과 1:1로 겹칩니다. 차이는 근거 장이 "현상 설명" 대신 "연구 수치"라는 점과 솔루션이 1장인 점뿐입니다.
- 경험 질문형(5장): 표지가 의문문입니다. 매트리스 본편 표지는 단정문이라 후킹 방식이 다릅니다. 골격(문제 → 팁 → 제품 → 마무리)은 같습니다.
- 수사 컨셉형: 수사 어휘·보고서 라벨·후렴이 핵심인데 매트리스 본편에는 어떤 장치도 없습니다. 해당 없음입니다.
- 연휴 프로모션: 혜택·가격·기간이 중심입니다. 매트리스 본편은 서비스 소개로 가격 요소가 없어 해당 없음입니다.
- 정리: 매트리스 본편은 배수구 4유형이 공통으로 깔고 있는 골격(표지 → 문제 근거 → 셀프 팁 → 솔루션 → 마무리)만 남은 상태이고, 후킹은 "수치 근거"에 기대고 있습니다. 검수본 스스로도 "기본형"이라 부릅니다.

## 2. 표지 후보 5종이 쓰는 후킹
- 후보 1 질문형("정말 끝났을까요"): 경험 질문형 계열의 반문 후킹입니다. 의문문 1회 규칙도 같습니다.
- 후보 2 장면형("가을 이불을 꺼내는 날" + 말풍선): 시즌 장면 지목으로, 연휴 프로모션의 "떠나기 전" 장면 후킹과 닮았지만 혜택이 없어 4유형 밖입니다.
- 후보 3 원인 추적형("빨아도, 갈아도, 돌아오는 알레르기 걱정" + 서브 원인 지목): 배수구 원인 추적형 표지와 문장 구조까지 같습니다.
- 후보 4 경험 질문형("겪어보신 적 있으신가요"): 배수구 경험 질문형 표지와 같은 틀입니다.
- 후보 5 수치형("40℃로 빨아도 사멸률 9.6%"): 본편 근거 1 헤드를 앞으로 당긴 수치 후킹으로, 배수구 편에는 대응 유형이 없습니다.

## 3. 선택지
- A. "기본형(근거 제시형)"으로 별도 분류. 근거: 표지가 질문도 수사도 아닌 단정문이고 근거 장 2장이 연구 수치 중심이라 기존 4유형 어디에도 장치가 없습니다. 배수구 4유형이 모두 이 골격 위의 변주이므로 기준형으로 두는 것이 분류상 자연스럽습니다. 바뀌는 것: 대시보드 유형 열에 "기본형" 1칸을 추가하고 매트리스 편을 등재합니다. 검수본은 그대로입니다.
- B. 원인 추적형에 편입. 근거: 장표 순서가 원인 추적형과 1:1이고 표지 서브에서 원인을 지목하는 방식도 같습니다. 표지를 후보 3으로 바꾸면 표지까지 완전히 일치합니다. 바뀌는 것: 대시보드에서 원인 추적형 열에 매트리스 편을 넣고, 검수본 본편 설명을 "원인 추적형 6장"으로 고치며 표지 교체 여부를 기획이 정합니다.
- C. 본편은 기본형으로 두고, 표지 후보별 파생 유형을 함께 표기(후보 3 → 원인 추적형, 후보 4 → 경험 질문형, 후보 1·2·5 → 기본형 변주). 근거: 이 편은 본편이 모두 같고 표지만 달라 유형이 표지 선택으로 결정됩니다. 표지가 확정되면 재분류 없이 표기만 바꾸면 됩니다. 바뀌는 것: 대시보드 매트리스 행에 "기본형 · 표지 후보로 원인 추적형/경험 질문형 파생" 한 줄을 적고 본편(#main)·표지 후보(#cover) 링크를 겁니다. 검수본은 그대로입니다.
